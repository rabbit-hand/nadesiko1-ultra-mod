## 🌸 これは何か

本プロジェクトは、クジラ飛行机氏が開発した日本語プログラミング言語「なでしこ（v1）」のオープンソース版コードをベースにしつつ、現代のWindows環境で使いやすいように機能を拡張する非公式プロジェクトです。

## 🚀 できること

見た目はいつものなでしこのまま、裏側では次のような現代的な作業を扱いやすくしています。

### 1. 🔒 セキュアな通信
- HTTPS / TLS を意識した安全な通信を行えます。
- Web API へ送受信し、JSON やテキストデータを扱えます。
- 非同期処理により、通信中もメイン画面の応答性を保ちやすくしています。

### 2. 📊 オフィス製品を自動化
- Excel や LibreOffice Calc などの表計算データを自動で書き込めます。
- 定型業務の入力・集計・報告作業を、スクリプトでまとめて実行しやすくしています。

### 3. 🗂️ ファイルとデータの処理
- テキスト・CSV・JSON・画像などを扱う自動化に向いています。
- 定型フォルダ操作、ファイル変換、一覧作成などを簡単に組み立てられます。

### 4. 🧩 現代環境に合わせた拡張
- Windows 10 / 11 での利用を想定した互換性改善を進めています。
- 旧来の依存関係を減らし、より扱いやすい形で使えるようにしています。

> なお、エディタ内の隠しAI補助機能は含めず、わかりやすい標準機能として整理しています。

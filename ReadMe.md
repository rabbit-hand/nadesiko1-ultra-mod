## 💡 本プロジェクト（Ultra-Mod）の概要と目的

本リポジトリは、オリジナル版の「簡単で親しみやすい日本語シンタックス」や、愛されるシンプルで美しいエディタ（noeditor）の外観・操作感を **100% そのまま維持** しつつ、裏側のエンジンを現代（2026年現在）のシステム環境や主流テクノロジーに適応させることを目的とした実験的プロジェクトです。

## 🌟 主な拡張アプローチ

- *ランタイムの最適化* ：スクリプトの実行速度向上および、最新のWindows環境における動作の安定化を図っています。
- *外部連携の拡充* ：モダンなAPIや外部デバイス、ネットワークプロトコルとの親和性を高めるアドオンの検証を行っています。
- *ビルドプロセスの効率化* ：配布用実行ファイル（EXE）の生成エンジンを改良し、より軽量で依存関係の少ないスタンドアロンファイルの出力を目指しています。

## 🚀 ウルトラモッド版の独自拡張機能（非公式追加機能）

見た目はいつものなでしこのまま、裏側のエンジンに以下の強力な命令や機能がネイティブにインジェクションされています。

### 1. 🔒 最新セキュア非同期通信 & 暗号化
古い外部 DLL への依存をバイパスし、Windows 11 等の最新環境で安全・高速に動作する通信基盤を構築しました。
- **最新セキュア送信** (`URLへとペイロードを最新セキュア送信`)
  - TLS 1.2 および最新の **TLS 1.3** 通信を強制指定し、セキュアな Web API との連携を可能にします。
  - バックグラウンドのマルチスレッド（非同期タスク）で実行されるため、通信中もなでしこの**メイン画面が一切フリーズしません**。
  - 届いた UTF-8 データを、なでしこ内部で文字化けしないよう Shift_JIS (CP932) へ自動で安全コンバートします。
- **SHA256計算** (`SのSHA256計算`)
  - 外部ファイルを必要とせず、Delphi コアの暗号化エンジンを用いて超高速に SHA-256 ハッシュ値を計算します。

### 📊 2. オフィス製品のマルチ自動化制御（MS Office / LibreOffice 両対応）
これまでの Word / Excel 制御に加え、現代の業務環境で広く普及しているオープンソースのオフィススイートにも対応しました。
- **リベラ表計算書込** (`SのSへSをリベラ表計算書込`)
  - **LibreOffice Calc** をバックグラウンドで直接制御し、指定したシート・セルへ文字やデータを高速に流し込みます。
- **最新エクセル書込** (`SへSを最新エクセル書込`)
  - Microsoft Excel (Office 365 を含む最新環境) を最適化されたルートで安全に自動操作し、データを注入します。

### 🧠 3. エディタへの「AIコード診断脳」の隠し融合
なでしこエディタ（なでしこぱっど）のデザインやレイアウトは **1ミリも変更していません**。
- **隠しショートカット (`Ctrl + F1`)**
  - コード入力中にこのキーを押すと、裏側で最新の AI が起動してスクリプトを自動診断します。
  - 助詞の使いミスや構文エラーを検知した場合、使い慣れたポップアップダイアログ形式で「修正理由」を優しく提案。
  - 承認（はい）を選択するだけで、エディタ内のコードを一瞬で正しい日本語スクリプトへ自動修復します。

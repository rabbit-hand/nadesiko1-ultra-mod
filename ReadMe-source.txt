================================================================================
                         なでしこ Ultra Mod について
================================================================================

本リポジトリは、なでしこ v1 のオープンソース版をベースに、
現代の Windows 環境でも使いやすいように機能拡張した非公式版です。

主な特徴
- 日本語のスクリプトで自動化できる
- Web API や HTTPS 通信を扱える
- Excel / LibreOffice などのオフィス作業を自動化できる
- ファイル・テキスト・CSV・JSON を組み合わせて処理できる
- 旧来の依存関係を減らし、現代環境に合わせた構成に近づける

================================================================================
開発環境
- Borland Delphi 6/7 で作成されたコードをベースにしています
- 主要なプロジェクトファイル
  - dnako.dpr
  - cnako.dpr
  - gnako.dpr
  - vnako/vnako.dpr

================================================================================
補足
- エディタ内の隠し AI 補助機能は含めず、標準的な機能として整理しています
- 詳細は ReadMe.md を参照してください
